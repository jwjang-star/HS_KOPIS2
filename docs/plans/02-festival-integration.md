# Phase 2 — 전국 행사·축제 연동

**상태: 조사 중 (API 후보 비교 진행 중, 구현 착수 전)**

## 배경

KOPIS(`pblprfr`)는 "유료 티켓 기반 공연장 공연"만 다룬다. 벚꽃축제·불꽃축제·지역 먹거리축제처럼 무료·야외·지자체 주최 행사는 KOPIS에 아예 안 잡히는데, 지점 주변 유동인구·숙박 수요를 만드는 완전히 다른 카테고리라 새 데이터 소스로 추가할 가치가 크다.

## 후보 API

### 후보 A — 한국관광공사 TourAPI 4.0(KorService2) `searchFestival2`
- data.go.kr 데이터셋 15101578("한국관광공사_국문 관광정보 서비스_GW")
- `https://apis.data.go.kr/B551011/KorService2/searchFestival2`
- 파라미터: serviceKey, MobileOS, MobileApp, _type(json), areaCode, sigunguCode, eventStartDate
- 관광지·숙박·음식점 등 15종 정보 중 하나로 "행사정보"가 포함된 종합 관광 API의 일부
- 지역코드(areaCode)가 KOPIS의 signgucode와 체계가 다름(서울=1, 부산=6, 제주=39 등) → 매핑 테이블 별도 필요. 정확한 값은 `areaCode2` 오퍼레이션으로 직접 조회해서 확정 권장
- 무료, 개발계정 1일 100,000트래픽

### 후보 B — 전국문화축제표준데이터
- (사용자 제안, 검증 예정) data.go.kr에 "표준데이터"로 등록된, 전국 지자체가 표준 스키마로 제출하는 축제 전용 데이터셋
- TourAPI보다 축제에 특화되어 있어 노이즈(숙박/음식점 등 무관 카테고리)가 없을 가능성
- 검증 필요 항목: 실시간 오픈API로 조회 가능한지(RestAPI/JSON) 아니면 정적 파일데이터(CSV 다운로드)뿐인지, 갱신 주기, 지역코드 체계, KOPIS/TourAPI와 좌표계·행정구역 코드 정합성

### 참고/보류 — 문체부 문화예술공연(통합) API (15121487)
- 연극/뮤지컬/오페라/콘서트/전시 등을 통합 제공하지만 KOPIS 커버리지와 상당 부분 겹침 — 우선순위 낮음
